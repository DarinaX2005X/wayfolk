# World assets

`kit.glb` holds only the pieces the island uses, baked with vertex colours by `tests/world/tools/bake-kit.py` from these packs:

| Pack | Author | License | Source |
| --- | --- | --- | --- |
| KayKit Medieval Hexagon Pack 1.0 | Kay Lousberg | CC0 1.0 | https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0 |
| KayKit Furniture Bits 1.0 | Kay Lousberg | CC0 1.0 | https://github.com/KayKit-Game-Assets/KayKit-Furniture-Bits-1.0 |
| KayKit Restaurant Bits 1.0 | Kay Lousberg | CC0 1.0 | https://github.com/KayKit-Game-Assets/KayKit-Restaurant-Bits-1.0 |
| KayKit Halloween Bits 1.0 | Kay Lousberg | CC0 1.0 | https://github.com/KayKit-Game-Assets/KayKit-Halloween-Bits-1.0 |

Houses, rocks, bushes, flowers, grass, clouds, sky, water and the surface textures are made in code (`src/world/`).
